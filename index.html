Connect the pipeline

Setup required

1. Install into the Fidobe source repository

Use the installer supplied with the pipeline package. It previews every file and preserves existing files.

python3 tools/install.py --target /path/to/fidobe-repository --addons addons --version 19.0
# Add --apply after reviewing the dry run.

2. Configure GitHub Actions

Set repository variables FIDOBE_CANDIDATE_BRANCH (for example develop-19.0), FIDOBE_RELEASE_BRANCH (19.0) and FIDOBE_BASELINE_REF (the last released branch or commit). For a genuinely new publication branch, explicitly set first_release: true in configuration.

Push the workflows to the default branch so the release and dashboard listeners are registered. Protect the publication branch from direct developer pushes. Enterprise modules require authorised source access and the configured dependency paths.

3. Connect this dashboard

Configure the Site's server environment with GITHUB_REPOSITORY=owner/repository and a secret GITHUB_TOKEN with read access to repository contents and Actions. The token remains on the server. The dashboard refreshes every 30 seconds.

4. Register and verify the Odoo Apps repository

Register the publication branch in the Fidobe vendor account and grant Odoo repository access. The pipeline records promotion separately from store verification. A store rescan integration has not been configured; no release is labelled store-verified without evidence.
